# ارزلرن (Arzlearn) — فرانت‌اند (فاز ۳)

React + TypeScript + Vite، متصل به بک‌اند Django (فاز ۱ و ۲).

## راه‌اندازی

```bash
cp .env.example .env
# در صورت نیاز آدرس بک‌اند را در .env تغییر دهید

npm install
npm run dev
```

سایت روی `http://localhost:3000` بالا می‌آید و به API بک‌اند در `http://127.0.0.1:8000/api` وصل می‌شود (قابل تغییر در `.env`).

> پیش‌نیاز: بک‌اند فاز ۱ و ۲ باید در حال اجرا باشد (`python manage.py runserver`) و CORS برای `http://localhost:3000` در `.env` بک‌اند فعال باشد.

## ساختار پروژه

```
src/
  api/          کلاینت axios + تایپ‌های TypeScript + توابع فراخوانی API
  context/      AuthContext (وضعیت ورود/خروج کاربر)
  hooks/        usePrices (بروزرسانی قیمت هر ۱ ثانیه)
  components/   Header, Footer, ArticleCard, AnalysisCard, PriceWidget, CommentSection, ...
  pages/        HomePage, CategoryPage, ArticlePage, LoginPage, RegisterPage, SearchPage
```

## نکات مهم پیاده‌سازی

- **هدر و فوتر مشترک**: در `components/Layout.tsx` روی همه صفحات اعمال می‌شوند.
- **دسته‌بندی‌ها**: کاملاً از `/api/articles/categories/` خوانده می‌شوند (بک‌اند-محور، مطابق درخواست).
- **احراز هویت**: توکن در `localStorage` (کلید `arzlearn_token`) ذخیره می‌شود و به‌صورت خودکار به هدر درخواست‌ها اضافه می‌شود.
- **اعتبارسنجی ثبت‌نام**: نام کاربری (فقط انگلیسی) و تطابق رمز عبور/تکرار آن به‌صورت آنی (real-time) در فرانت‌اند بررسی می‌شوند؛ خطاهای بک‌اند هم زیر هر فیلد نمایش داده می‌شوند.
- **قیمت لحظه‌ای**: هوک `usePrices` هر ۱ ثانیه endpoint قیمت‌ها را poll می‌کند تا هیچ‌وقت عقب نماند.
- **دیدگاه‌ها**: فرم ثبت دیدگاه فقط برای کاربران لاگین‌کرده نمایش داده می‌شود؛ در غیر این صورت لینک ورود نشان داده می‌شود.
- **ریسپانسیو**: در حالت موبایل، هدر به همبرگری (چپ) + لوگو (وسط) + دکمه ورود/ثبت‌نام (راست) تبدیل می‌شود.

## Build برای پروداکشن

```bash
npm run build
```

خروجی در پوشه `dist/` قرار می‌گیرد که می‌توانید آن را روی هر سرویس استاتیک (Nginx و غیره) سرو کنید.

## گام بعدی (فاز ۴)
بروزرسانی قیمت لحظه‌ای از طریق WebSocket (Django Channels) به‌جای polling، برای کاهش تاخیر و بار روی سرور.

## فاز ۴ — قیمت لحظه‌ای با WebSocket

هوک `usePrices` دیگر polling نمی‌کند؛ به `ws/prices/` بک‌اند وصل می‌شود و قیمت‌ها را
بلافاصله بعد از هر بروزرسانی (سمت سرور) دریافت می‌کند. یک دایره‌ی سبز چشمک‌زن
کنار «قیمت لحظه‌ای» وضعیت اتصال زنده را نشان می‌دهد.

- در صورت قطع اتصال، بصورت خودکار با تاخیر فزاینده (۱ تا ۱۵ ثانیه) دوباره وصل می‌شود.
- برای نمایش فوری قبل از برقراری WebSocket، یک درخواست REST اولیه هم زده می‌شود.
- آدرس WebSocket از `VITE_WS_BASE_URL` در `.env` خوانده می‌شود (پیش‌فرض: `ws://127.0.0.1:8000`).

> پیش‌نیاز: بک‌اند باید Redis را در دسترس داشته باشد و با `python manage.py runserver` (که بعد از فاز ۴ هم HTTP و هم WebSocket را پوشش می‌دهد) و `python manage.py update_prices` در حال اجرا باشد.

## فاز ۵ — سئو و تقویم اقتصادی

- **useSEO hook** (`src/hooks/useSEO.ts`): تایتل، متا تگ‌ها (description/OG)، canonical، و JSON-LD هر صفحه را مدیریت می‌کند. چون این یک SPA بدون SSR است، این بهترین‌تلاش ممکن برای سئوی سمت کلاینت است.
- **Schema.org**: `src/utils/seo.ts` شامل توابع ساخت داده‌ی ساختاریافته (Organization، WebSite، Article، BreadcrumbList) است؛ در `HomePage`، `ArticlePage` و `CategoryPage` استفاده شده‌اند.
- **Code splitting**: در `App.tsx`، همه‌ی صفحات به‌جز صفحه اصلی با `React.lazy` بارگذاری تنبل می‌شوند تا حجم بسته‌ی اولیه کمتر شود.
- **Lazy loading تصاویر**: تمام کارت‌های مقاله/تحلیل/صرافی از `loading="lazy"` استفاده می‌کنند.
- **صفحه‌ی جدید** `/economic-calendar`: نمای هفتگی داده‌های اقتصادی با تم اختصاصی (نوار تیره‌ی هر روز شامل تاریخ شمسی، میلادی و اسم روز).
- **robots.txt** در `public/robots.txt` — بعد از دیپلوی، آدرس واقعی sitemap بک‌اند را جایگزین کنید.
